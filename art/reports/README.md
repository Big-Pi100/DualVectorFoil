# reports/ · 门禁与实验记录（来源项目原档）

> 这两份是《二向箔》Godot 版（`E:/Dual_Vector_Foil`）在 2026-11-26 通过 **G1–G5** 时的原始评审记录，
> 随规范一起原样移植过来，用途是**改规范前先看判定依据**，不是本项目自己的实验台账。

## 为什么里面有找不到的文件

`Gate_Review.md` / `Experiment_Log.md` 里提到的 `*.gd` 脚本与 `*.tscn` 场景
**都属于来源 Godot 工程**，本项目是 Canvas 2D，没有也不该有这些文件。

`asset_audit.py` 的「文档死引用」检查会把它们报成 P2 —— **是预期行为，不是缺陷**。
判读口径：这两份报告里的 `.gd` / `.tscn` 路径一律忽略；**`.png` / `.md` 路径必须存在**（那是资产与规范）。

## 本项目自己的记录写哪

新资产的实验记录按 `ART_GUIDE §8.2` 的字段补在 `approved/manifest.json` 的 `note` 里，
不另开台账 —— 一条资产一行，source → approved 可追溯，比另写一份 md 更不容易过期。
