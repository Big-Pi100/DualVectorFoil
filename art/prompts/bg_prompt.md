# 背景出图配方（C 类：视差背景层）

> 骨架与 `sprite_template.txt` 共用同一段 **Medium / PROPORTIONS / 配色**，
> 只改三处：①去掉洋红底与绿分割线（背景是整幅使用，不抠图）②去掉分行/多格
> ③把 L2「完成度」判据从"主角"翻成"世界"。
>
> **为什么要单独一份**：精灵表的 prompt 已经被白哥订死（"背景和分割线订死，其他字段也都固定死"），
> 那份不许再动。背景是另一类资产，允许有自己的骨架 —— 但**笔触段落必须逐字相同**，
> 否则不是同一支笔。

## 与精灵表共用、不许改的段落

- `Medium: real wax crayon, waxy broken color, ... irregular ~3px hand-drawn contour, wobbly lines, no smooth vector curves. Flat 2D graphic.`
- 12 色板（`STYLE_LOCK.md` L5）

## 与精灵表相反、必须改的三处

| 项 | 精灵表 | 背景 |
|---|---|---|
| 底色 | 纯洋红 #FF00FF | **纸底 #E8DCBE**（整幅使用，不抠） |
| 分割线 | 纯绿 #00FF00 | 无 |
| 完成度 | 完成品（闭合 3px、涂满、不出界） | **未完成品**（断续 1px、纸白 30–50%、出界 3–8px） |

## 一个必须记住的因果

L2 判据里主角和世界**同色板、同笔**，唯一的差别是"画完没画完"。
所以背景的 prompt 里必须出现"比站在它前面的成品角色明显更草"这一句 ——
否则模型会把背景也画成完成品，主角就糊进去了（这正是 L2 反面示例里那排草犯的错）。

## 尺寸

`1536×1024`（3:2）。游戏视口 960×540，横向平移时要覆盖 32 格 × 48 = 1536px 的房间宽度。
平铺接缝用**镜像拼接**处理（左右翻转首尾相接），蜡笔笔触镜像后几乎看不出。
