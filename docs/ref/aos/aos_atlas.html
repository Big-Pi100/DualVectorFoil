2. 等级成长

HP 是完美线性（320 + 12×(L−1)）；LCK 也是纯直线；STR / CON 是五段折线，斜率在 +1 / +2 / +3 / +2 / +1 之间切换，但**整条线仍然接近直线** —— 归一化后几乎看不出弯。 这是全图最要紧的一点：《晓月》的等级成长没有指数段。它的爽感不来自「升级越来越快」， 而来自「换了一件装备，战力突然跳一档」。

4. 11 个强制 BOSS：招式少，受击面变

招式数的中位数是 2。前七个 BOSS 里六个只有 2–3 招。 但 11 个里有 8 个的受击面不是「全身一个判定」—— AoS 用「你打哪里、你站哪里」制造难度，不用「它多几招」。 巴洛尔最极端：身体不伤人、拳头打不掉血，于是最安全的位置在砸下来的拳头正下方。

4.1 每场战斗：打哪里，怎么躲

1. 吱嘎骷髅2 招 / 1 阶段

single · 全身一个判定
巨棒横扫 · 整个上半身后仰、棒子举过头顶
→ 挥完立刻贴身砍 2–3 下再退，等下一下
吸火吐球 · 身体前倾、有吸气动作，比挥棒更慢
→ 跳过去或蹲下躲，火球速度低
教什么：前摇 → 闪避 → 反击窗口。全游戏唯一一个「零惩罚教学」

2. 蝎尾狮2 招 / 1 阶段

single · 全身一个判定
前进火球 · 停下脚步、张口
→ 留在地面，进两步砍两刀，跳火球后后撤
接触伤害 · 无前摇（被动）
→ 不能贴脸站桩，打完必须退
教什么：数值墙：同样的操作，等级不够就是过不去

3. 大装甲2 招 / 1 阶段

directional · 正面被盾挡住，只有挥砍后的窗口能造成伤害
盾牌格挡 · 举盾前顶
→ 不能硬砍正面。等它先挥，挥完的硬直里打
单手挥砍 · 肩部下沉、盾微微让开
→ 后撤闪过，立刻回到正面砍一刀再退
教什么：第一次「不能站桩对砍」：要读它的出招节奏找窗口

4. 大巨人2 招 / 1 阶段

part_immune · 手臂不可伤。有效部位是腿和身体 —— 要走到脚边打
巨臂下砸 · 蹲下或举拳（两个前摇都指向同一招）
→ 后撤退出攻击范围，砸完再进。手臂本身打不掉血
吐石 · 仰头
→ 跳过去或侧移
教什么：第一次「打错地方等于没打」。玩家的默认反射（打伸过来的那只手）是错的

5. 猎头者3 招 / 3 阶段

form_swap · 三次整只换掉，换的是「移动方式 + 攻击距离」：近身 → 浮空远程 → 贴地中距
形态一 · 匕首战士 · 换形态时整只重组
→ 保持半屏距离，等她落地贴过来时打
形态二 · 飞行法师 · 起飞、法杖抬起
→ 蹲下躲火，绝不站在雷柱上
形态三 · 蜥蜴爬行者 · 伏地、舌头后缩
→ 不要站在她正前方一条线上
教什么：形态切换不是为了「多几招」，是为了逼你换站位。三形态对应三个安全距离

6. 死神3 招 / 2 阶段

single · 单体，但两形态血量分开算（2000 + 2444）
巨镰贴地滚 · 举起镰刀、后仰蓄力
→ 跳过或站到镰刀线外，过去之后立刻反击
小飞镰 · 抬手，镰刀离体
→ 小范围走位就能穿过去，不要翻滚过度
闪烁横扫 · 身体闪一下（唯一提示，很快）
→ 看到闪光就后撤，不要等它出现再反应
教什么：第一次「前摇短到接近反应极限」。前面所有 BOSS 教的「看动作再闪」在这里不够用了，必须预判

7. 死人军团2 招 / structural 阶段

shell_core · 壳（外层尸体）+ 核（内部本体）两段。圣属性是弱点，所以破壳最快的是圣剑
外层零件 · 无（常驻）
→ 先清外层。打核心之前外层会挡伤害
核心激光 · 外壳剥落、核心发亮
→ 保持移动，蹲下躲低角度那几条
教什么：血条不止一条。伤害先被外壳吃掉，玩家要判断「现在打的是哪一层」

8. 巴洛尔3 招 / 1 + 半血狂暴 阶段

threat_split · 它的身体不伤人，只有拳头伤人；而拳头又打不掉血。能打的是身体/头，能伤你的是拳
单拳下砸 · 拳头向后收
→ 收到「头正下方」：拳头回收时两边都打不到你
双拳交替 · 双肩同时抬起
→ 往它落下那一侧的反方向走，砸完再回到中间
半血火墙 · 血量过半（事件触发，无动作前摇）
→ 跳过火墙，保持在中线附近
教什么：威胁源和受击点可以是两个东西。玩家的「离危险远一点」直觉在这里失效 —— 最安全的位置在最危险的拳头正下方

9. 格拉罕·琼斯5 招 / 2 阶段

multi_part + decoy · 形态二有四个部位：头（4000）、双手（各 2000）、躯干（2000）。只有躯干必死，其余可无视。躯干只能跳攻打到。形态一 throne 上还有一团 5000 HP 的不可打实体，专门骗伤害
形态一 · 传送 · 身影消散
→ 不要追。等他出现在近处再砍
形态一 · 五芒星火球 · 双手抬起，身周出现光点
→ 站在他身边贴砍（近身时火球打不到）
形态一 · 红色光柱 · 地面先出现红色圆形标记
→ 看地面，不要看天
形态二 · 追踪头光柱 · 头部转向你、停住
→ 持续移动，别停在原地
形态二 · 手掌扫地 · 手降到地面高度
→ 跳起。这也是你唯一能打到躯干的姿势
教什么：目标选择：同屏四个部位，只有一个值得打。「全都打」等于拖长战斗、多吃伤害

10. 尤里乌斯·贝尔蒙特2 招 / 1 阶段

threshold_end · 血量降到阈值时战斗直接结束 —— 不是打到 0。Soma 会喊「STOP! I'VE HAD ENOUGH!」
开场对话 · —
→ 对话结束才开打，别在对话里松手
贝尔蒙特连击 · 起手动作
→ 用火焰恶魔（红魂）远程消耗，不要近身对拼
教什么：血条清零不是唯一的结束条件。这一场打赢了也不杀死对方 —— 用规则本身讲剧情

11. 混沌6 招 / 2 阶段

multi_part + decoy · 形态一：头颅不可打，只有 3 个球可打（强制清场）。形态二：核心必死，四角眼是纯干扰
形态一 · 房间旋转 · 无（常驻）
→ 站位要跟着场地一起转，不能按固定坐标记
形态一 · 三球环绕 · —
→ 头颅本身打不到，只能打三个球。保持距离，别被球刮到
形态一 · 激光环 · 环成型前一瞬
→ 看环的缺口，穿过去
形态二 · 核心 · 核心暴露
→ 集中打核心，别管四角眼
形态二 · 四角眼 · —
→ 无视。打它们是浪费输出窗口
形态二 · 骨蛇扫场 · 从边缘出现
→ 跳或贴内圈
教什么：把前面所有课合起来考：目标选择（打哪个）+ 站位（场地会动）+ 输出窗口（只有跳攻/远程够得到）
