# 参考分析：《重生细胞》手机版的操作与 HUD

日期：2026-11-24 · 触发：白哥提出"四格装备栏 + 三个动作键"的界面更适合现代
性质：**参考分析 + 改造方案**。本文不改代码，只给判断依据和落地切分。

---

## 0. 一句话结论

《重生细胞》手机版真正值得抄的不是"按钮变少了"（它其实有 7 个可点区域，和我们一样多），
而是**把可点区域分成了两类**：

| 类别 | 位置 | 大小 | 内容 |
|---|---|---|---|
| **动作键**（跳跃 / 翻滚 / 交互） | 拇指落点 | 最大 | 永远不变，不用记 |
| **装备槽**（2 武器 + 2 技能） | 屏幕上缘 | 较小 | 会随配装变，**常驻可见** |

我们的 7 个按钮现在长得一模一样，所以玩家分不清"每次都要用的"和"有了才用的"。
WO-003 用"大小不同"去补这件事，方向对，但只补了一半——真正的分界是**常驻 vs 菜单**。

## 1. 事实核查

### 1.1 控件清单（以截图 + 多方攻略交叉确认）

| 控件 | 位置 | 行为 |
|---|---|---|
| 浮动摇杆 | 左半屏 | 按住任意处就地生成；**上下推也是修饰键**（下推 + 跳 = 下落坠击） |
| 跳跃 | 右下 | 点按跳，空中再点二段跳 |
| 翻滚 | 右下 | 点按翻滚，**带短暂无敌帧**；可滑动改变方向（可选设置） |
| 交互 | 右下 | 对话、购物、拾取、开门，**全部一个键** |
| 装备槽 ×4 | 屏幕右缘（旧版竖排） | 2 武器 + 2 技能；**点一下就用**；技能带冷却，槽上显示冷却 |
| 血瓶 | 左缘 | 回血，一次性 |
| 生命/资源 | 左上 | 血条 + 数字 + 三种卷轴层数 + 金币/细胞 |

关键细节（这三条最容易被忽略，但最值得学）：

1. **攻击没有独立按键**——它就在"主武器槽"里。所以"四格装备栏"不是装饰，
   它是把"攻击"也变成了装备。这也是为什么右侧只需要 3 个动作键。
2. **技能槽有冷却，且冷却画在槽上**。槽同时承担"有什么"和"能不能用"两个信息。
3. **装备常驻屏幕，不需要开背包**。玩家永远知道手上有什么——这一点直接决定了
   我们"首玩者找不到魂匣"的问题。

### 1.2 顺手记下的反面教材

官方攻略里反复出现一句："**血瓶的位置很容易让人忽略**，很多玩家苦于血量不足却
不知道如何回复。" 一条命的中后期功能，因为放在边缘而没人看见。
→ 这条对我们是警告：**四格一旦放到屏幕边缘，就必须足够显眼**，否则会重演"看不见＝不存在"。

### 1.3 来源

- `dead-cells.com` 官方：RogueVania / souls-lite 战斗定位
- 小米游戏中心《第一次该怎么玩重生细胞》：键位从左到右 = 两个技能键、两个武器键、最右三个翻滚/跳跃/交互键；技能有冷却只能带两个；翻滚有无敌帧；交互负责对话/购物/拾取
- `jaqly.com` 操作说明：右侧 large dedicated action buttons for two main weapons and two skills；空中下滑 = 地面猛击；盾牌格挡要卡时机
- 百度文库《死亡细胞手游操作进阶指南》：长按图标看属性、左右滑动换武器、**可自定义按键位置/大小/透明度**、可选自动攻击

## 2. 逐项对照

| 维度 | 《重生细胞》 | SoulKeep 现状 | 差距 |
|---|---|---|---|
| 移动 | 浮动摇杆，上下推 = 修饰 | 浮动摇杆，上下推 = 抬头/蹲 | ✅ 一致 |
| 跳跃 | 点按 + 二段跳 | K，含二段跳/土狼/缓冲 | ✅ 一致 |
| 翻滚 | 点按，**有无敌帧** | 后跃 I，`invuln 0.12`（只覆盖前 60%） | ✅ **我们已经有**，只是名字叫"后跃" |
| 交互 | 独立键，承接所有互动 | 无（拾取自动、传送门碰触） | ❌ 缺 |
| 攻击 | **在武器槽里**，无独立键 | J，独立键 | ⚠️ 键位性质不同 |
| 主动技能 | 2 格，带冷却 | 红魂 U、蓝魂 L，消耗"墨"不是冷却 | ⚠️ 资源模型不同 |
| 装备可见性 | **4 格常驻** | 需按 O 开魂匣 | ❌ 差最大的一项 |
| 装备数量 | 4 格全都有内容 | 主动只有 2 个（红/蓝），黄/银是被动 | ❌ **最大风险，见 §3** |

> **这张表只比"有什么"，不比"按下去被不被接住"。**
> 后者（输入缓冲 / 动作解剖 / 取消出口 / 判定窗口 / 反馈）另见 **`ACTION_CHAIN.md`** ——
> 2026-11-24 白哥指出这张对照缺了「操作-动作」层之后补的。真正的判据是后者。

## 3. 三个真问题（不是"少了按钮"）

### 3.1 四格里有几格真有内容？

Dead Cells 的四格是 **2 武器 + 2 技能**，全部可点、全部有用。
SoulKeep 的魂是：

```js
fire  → red   主动，耗墨 12
axe   → red   主动，耗墨 10
glide → blue  按住，持续耗墨
sight → yellow 被动（看见可破坏的墙）
djump → silver 被动（二段跳）
```

**主动只有 2 个**。照搬四格，会有两格长期是空的——比现在更糟，因为空格会
持续提醒玩家"你缺东西"，而 Dead Cells 的格子从来不会空。

→ 所以"四格"不是布局问题，是**内容问题**。这一格必须先定装什么（见 §4.3）。

### 3.2 "按住"的动词放不进"点一下就用"的格子

我们的四个可操作物里，有两个是**持续动词**：

- 蓝魂（翼魔）：按住减缓下落
- 纸（侧身）：按住变薄

Dead Cells 的格子里全是瞬时动作。硬塞进去会得到一个"点了没反应"的格子。

→ 处理办法：格子保留这两种语义，用**不同的视觉**区分（点按 = 实心图标，
按住 = 图标右下角一个"按住"角标 + 长按有进度反馈）。这个机制我们 WO-003 已经有了，
可以直接复用，不需要新发明。

### 3.3 我们的"攻击"该在键上还是在格子里？

Dead Cells 把攻击放进武器槽，省出一个键位。我们如果照搬：

- 好处：右侧只需 3 个动作键，拇指负担最小
- 代价：**攻击从"永远有"变成"要看着格子按"**。SoulKeep 的普攻是最高频动作
  （也是击碎识破墙的手段），把它从拇指落点挪到屏幕上缘，手感会退化

→ 我的判断：**攻留在动作键位**（最高频的动作必须在拇指底下），四格装
红魂 / 蓝魂 / 纸 / 第四格。理由写在这里，方便以后被推翻时有据可查：
Dead Cells 敢把攻击放进槽，是因为它有"自动攻击"这个可选项兜底；我们没有。

## 4. 推荐映射

> **2026-11-25 补记**：本节写于 11-24 早，那时侧身（纸）还在，所以四格里排了「纸」。
> 侧身已于 11-25 删除（`DESIGN_A.md` §9），第 2 格改为「未装备」空槽。
> 下面保留原文，是为了留住"当时为什么这么排"的判断依据。


### 4.1 右侧三分区

```
                     ┌── 装备槽（屏幕右缘，竖排，四格）
                     │   ① 红魂  （点按，耗墨）
                     │   ② 蓝魂  （按住，持续耗墨）
                     │   ③ 纸    （按住，侧身）
                     │   ④ ？    （待定，见 4.3）
                     │
   [摇杆]            │            (跳) (后跃) (交互)
   左半屏            │             拇指落点，三键
```

### 4.2 动作键（3 个，拇指落点）

| 键 | 原名 | 行为 | 为什么放这里 |
|---|---|---|---|
| 跳 | K | 跳 / 二段跳 / 下推+跳=滑铲 | 最高频 |
| 冲刺 | F（旧键 I） | 地面位移，`invuln 0.12` | **这就是我们的翻滚**，只是名字不现代 |
| 交互 | O / Tab | 开魂匣；接入未来的拾取/开门 | Dead Cells 用同一个键收掉所有互动 |

> 命名建议：`后跃` → `翻滚`。它已经是"带无敌帧的位移"，功能上完全等价，
> 换个名字玩家立刻懂。这是零成本改动。

### 4.3 第 4 格装什么（需要策划定，三选一）

| 方案 | 内容 | 代价 |
|---|---|---|
| **A. 黄魂主动化** | 识破之魂从被动变成"点一下，3 秒内看见可破坏的墙" | 改玩法，要重做识破的判定入口 |
| **B. 消耗品** | 新增"墨囊 / 符纸"类一次性道具，点一下用掉 | 要新增物品系统，范围最大 |
| **C. 留空并明示** | 显示虚线空槽 + "未装备"，和 Dead Cells 一样四格但承认缺 | 零成本，但会暴露内容不足 |

**我建议 A**：它是唯一既补内容又不新增系统的选项，而且"识破"本来就是
"看一眼"的动词，主动化比被动更贴它的名字。但它改的是玩法，必须策划点头。

### 4.4 明确不照搬

| 不抄 | 为什么 |
|---|---|
| 自动攻击 | 我们没有"武器多样性"来支撑它；普攻是手感核心 |
| 滑动切武器 | 我们只有 2 个主动，切了也没得切 |
| 随机武器掉落 | 我们是能力解锁型，不是 rougelite 配装 |
| 血瓶放边缘 | 见 §1.2，那是它自己被吐槽的设计 |

### 4.5 拇指可达性：原型测出来的一个真代价

我把两套布局做成了可点击原型（`mock_touch_layout.html`），可以在页面上叠加"拇指可达范围"：

| 控件 | 落在哪 |
|---|---|
| 跳 / 翻滚 | **内圈（舒适区）** |
| 交互 | 内圈边缘 |
| 装备格 ④（最下面一格） | **外圈（勉强够到）** |
| 装备格 ①②③ | **圈外 —— 必须抬拇指** |

也就是说，**竖排四格的上三格，玩家在战斗中要抬拇指才能够到**。《重生细胞》是一样的：
它用"必须抬手"换"永远看得见"。这个交换在它那里成立，因为它有 4 格真装备、
有自动攻击可选项兜底；在我们这里要成立，得先解决 §3.1（只有两格有内容）。

如果实测下来"抬手"确实影响手感，备选是**把四格从竖排改成 2×2 贴在动作键正上方**：
拇指原地向上挪半格就够到，代价是更靠近动作键、可能误触。
这一条建议**等真机试玩再定**，不要在原型阶段就拍板。

## 5. 代价与风险（照实说）

| 改动 | 影响面 | 风险 |
|---|---|---|
| 右侧 7 键 → 3 键 + 4 格 | `mobile.js` 布局、`index.html` CSS、`ui_check.js` 全部触屏断言 | 中：纯布局，判定不动 |
| 后跃改名翻滚 | 文案（`LEGEND`）、`DOC_CONTROLS.md` | 低 |
| 交互键 | 需要把"开魂匣"从 `匣` 迁过去，并处理菜单关闭 | 中：菜单开关路径只有一条，得测 |
| 第 4 格 | 取决于方案 A/B/C | **高**：动玩法 |
| 装备常驻可见 | 魂匣的"操作/魂槽"页签仍需保留（完整说明），但入口从"必需"降为"补充" | 低 |

**必须守住的一条**：这一轮只改**布局与命名**，不改任何判定、数值、关卡、敌人、
Flatten 机制。理由：我们刚把输入层修到 389 项全绿（含中文输入法、触屏本误判、
摇杆垂直轴复位），不能再把它推倒重来一次。
