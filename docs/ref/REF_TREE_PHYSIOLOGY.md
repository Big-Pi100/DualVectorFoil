# REF · 世界树的生理（事实底座）

> 建 2026-11-27。为 `05 §1.3` 那条主线（**运输与产生出问题**）提供可查的依据。
> **这份不做植物学教程，只做一件事：区分「哪些机制能用」「哪些不能用」。**
> 判断标准：一条设定如果对不上生理，就是硬加的。

---

## 1. 为什么需要这份

白哥 11-27 给的主线只有一句：世界树被入侵，**物质的运输和产生都出了问题**。

这句话要么落成"设定书上的一段话"，要么落成**一套能judge新机制的尺子**。
落成后者需要三个前提：两条流是什么、它们能不能独立坏、坏了多久看得出来。
这三个都有确定答案，所以值得建档案 —— 否则三个月后写关卡时又会凭印象编。

## 2. 两套运输系统

| | 上行 | 下行 |
|---|---|---|
| 走什么 | 水 + 溶解矿质 | 蔗糖 + 有机物 |
| 方向 | 根 → 叶，**单向向上** | 叶 → 根/果，**主要向下**（源→库） |
| 在哪 | 木质部（木头里，树皮之内） | 韧皮部（树皮内层） |
| 细胞 | 成熟即死（导管/管胞） | 活的（筛管 + 伴胞） |
| 动力 | 蒸腾拉力 | 压力流 |

夹在中间的是**形成层**（cambium）——一层薄的分裂细胞。
"树皮"在解剖上就是形成层以外的全部，所以**剥皮 = 剥掉韧皮部，木质部不动**。

> 这一句是全部设定的支点：**两条流在物理上被一层薄膜隔开，所以能分别坏。**

## 3. 环剥：一条切口，两个独立的失败模式

环剥（girdling）是绕树干剥掉一圈树皮。结果非常干净：

| 项 | 结果 |
|---|---|
| 韧皮部 | 断 |
| 木质部 | **完好** |
| 根 | 断糖 → **饿死** |
| 叶 | **照样有水、照样绿** |
| 蒸腾 | **没有立刻受影响** |
| 地上部分外观 | **能健康数周到数月** |
| 切口上方树皮 | 糖堆积 → **肿胀** |
| 切口下方 | 逐渐死亡 |
| 松树苗断糖后存活 | **140 天以上** |
| 有效环剥宽度 | 10–15 cm（太窄会被桥接愈合） |

**这是我要的诊断学：树被掐住时，从上面看不出来。**
玩家在冠部打得顺、叶子绿得发亮，而根已经在耗尽淀粉。

> 反面同样成立：木质部栓塞（缺水）→ 叶子立刻萎蔫，**看得见**。
> 所以"上行的坏"是急症、肉眼可见；"下行的坏"是慢症、肉眼不可见。
> **两种坏法给两种节奏**：一个逼你马上处理，一个等你发现时已经晚了。

## 4. 伤口：树不愈合，它只隔离

| 项 | 事实 |
|---|---|
| 会不会长回原样 | **不会**。术语上 "healing" 是误称 |
| 实际过程 | 区隔化（CODIT），在伤口边缘长**愈伤组织**把伤包起来 |
| 愈伤开始 | 受伤后 **2–4 周** |
| 小伤口封口 | **1–2 个生长季** |
| >2 英寸（约 5cm）伤口 | **3–5 年** |
| 愈伤从哪长 | **两侧最快，上下慢** |
| 伤口涂封剂 | **无效**（未证明加速封口或减少感染，闷湿反促腐） |
| 秋季受伤 | 比春夏慢约 **20%** |

两条能直接用的：

1. **"从边缘往里收"是有依据的视觉**——愈伤从两侧长，所以断面的收口动画应该是
   **左右两边先合、上下后合**，不是四边均匀缩。这个细节不用解释，玩家看得出来。
2. **封口要消耗能量**，而能量是糖，糖来自叶。所以"种田供料 → 树封口"这条链
   **不是编的**，它符合真实的碳分配逻辑。

## 5. 寄生：一根管子，既抽又注（2026-11-27 白哥定怪物本质）

白哥定的三件事：
**① 怪物是入侵者，在现实里就是寄生虫；② 目的是把世界树变成黑暗世界树，
所以它们不但吸取物质养料，还注入黑暗物质；③ 怪物有外来物种，也有原生物种被黑暗化。**

这四小节分别回答：注得进去吗（5.1）、会不会扩散（5.2）、黑是什么（5.3）、
被改写长什么样（5.4）。四条全是可查的植物病理学，没有一条是编的。

### 5.1 吸器是**双向**的 —— 这是"注入"唯一的物理通道

| 项 | 事实 |
|---|---|
| 器官 | **吸器**（haustorium），拉丁语 *haurire* = 喝 |
| 有多少种寄生植物 | 约 **4000 种**，占被子植物约 **1%** |
| 接到哪 | 寄主的**维管束** —— 木质部与韧皮部**都接** |
| 方向 | **双向（bidirectional）** |
| 运什么 | 水、无机盐、光合产物、**mRNA、蛋白质、次生代谢物、病毒、植原体** |
| 已知可传病毒数 | **56 种**能经菟丝子从病株转到健株 |

**这一条把"注入"从设定变成了机制。** 吸器不是单向吸管，是双向通道 ——
所以"吸走养料"和"注入黑暗物质"用的是**同一个器官**，不需要两套设定。

> 如果吸器是单向的，"注入"就得另编一个理由（毒腺？孢子？），
> 而每多一个理由，世界观就多一处将来会被问倒的地方。

### 5.2 它是一张**网**，不是一条虫

一株菟丝子能同时寄生多个相邻寄主，把它们**连成一张网**；抗虫信号（茉莉酸）
可经这张网传到 **1 米外**的另一株寄主，并诱导它的抗性。

三个后果，都不用另编：

| 后果 | 落在哪 |
|---|---|
| 感染会**跨区**扩散 | 不用解释"怪物为什么会跑到别的区" |
| 清干净一个区，它可能从邻区**重新接上** | `03 §5` 的"感染复发"有了物理依据，不是数值拍脑袋 |
| 招安一个兵种 = 把网上的一个节点**翻转**过来用 | `03 §6` 的守卫军不是"雇来的"，是"接过来的" |

### 5.3 变黑和堵管是**同一个过程**

病原真菌侵入木质部后的真实链条：

```
菌丝 + 分生孢子占满导管空间
  + 分泌毒素
  + 刺激薄壁细胞产生凝胶 / 侵填体（tylosis）
        ↓
     导管栓塞
        ↓
颜色：黄褐 → 黑褐（堵塞越重，色变越重）
        ↓
水分上不去 → 上部枝干缺水枯死
```

**蓝变真菌（blue-stain）还会在菌丝里产生黑色素**，把边材染成深蓝到黑 ——
所以"黑"是有物质来源的，不是一个滤镜。媒介是**树皮甲虫**：它钻蛀时把孢子带进去。

**这是本次最省事的一条：黑暗化不用另立一套设定。**

> 玩家看到的黑，就是堵。
> 一个视觉承担两件事，玩家不用被解释两次。

而且"变色先于枯死"与 §3 环剥的结论**是同一条**：
**树总是先变心，再变样。**

### 5.4 原生物种是被**改写**，不是被替换

矮槲寄生 / 植原体 / 部分真菌感染后的真实形态：

| 项 | 事实 |
|---|---|
| 长成什么 | 寄主组织**异常增生**，长出一簇纠结丛生的枝条 —— **女巫扫帚**（witches' broom），枝条肿胀 |
| 潜伏 | 病原先在皮下长 **2–3 年**才冒芽；**冒出来时，看着健康的枝条早已感染** |
| 后果 | 先让树"长得不像自己"，再让它衰退 -> **形态改写先于死亡** |

**这条决定了"原生物种被黑暗化"该怎么画：**

> 不是变成另一种怪物，是**还是它，但长歪了**。
> 玩家认得出它原来是树里的什么 —— 这比"凭空冒出魔物"有效得多。

也决定了**招安的依据**：能被改写的东西，就能再被改回去。
改回来也带着痕 —— 与 §1 内核（回不去原样）和 §4（只隔离不愈合）同一条线。

### 5.5 一条不能过界的：树能带着烂心活着

心腐（heart rot）真菌**只吃心材（死组织），不碰活的边材**，
木质部每年推进 **6–8 cm**，而**树照样在腐烂的心材上继续生长**，可以活上百年。

这是"带疤活着"最硬的物理版 —— 空了也能站着。

> **但这里不能跨界。** "内部腐烂进度"一旦做成进度条，就是 `05 §1.7` 禁止的
> 健康度数值。正确的用法只有一个：**心腐是画面**（剖面能看到黑心），不是仪表。

## 6. 物资两分：能种的，和不能种的

白哥定的第二件事：**物资来源两分 —— 世界树原住民的种植物（战斗物资），
世界树本身的产出（稀有、任务物品）。**

| | **可种**（原住民培育） | **不可种**（树自己产出） |
|---|---|---|
| 是谁的 | 世界树**原住民** | **树本身** |
| 是什么 | 把树液/树脂培育成的武器与防御组织（刺、硬壳、弹体） | 树脂、树胶、单宁、虫瘿（gall）、心材、果实 |
| 可再生 | 是，有节奏（30 分钟一茬） | **否**，采完要等树重新分泌 |
| 系统里是 | **战斗物资**：弹药 / 强化 / 成长 / 兵营 | **稀有 / 任务物品**：解锁、开门、剧情 |
| 拿法 | 播种 → 等 → 收 | 走到特定位置采 |

**分界不是"贵不贵"，是"能不能种"。** 这条分界带来三个后果，都是白要的：

| 后果 | 为什么 |
|---|---|
| **防刷** | 稀有物品不能种，只能去特定位置采，刷不出来 |
| **给"回老区"具体目的** | 树的产物长在特定位置（某处渗脂的断面、某个树瘤），不是每个区都有 |
| **主线不能被刷绕过** | 任务物品一旦可量产，玩家就能靠种田跳过整个关卡 |

而两层之间有一道**加工**，它正好解释了原住民为什么不可替代：

> 树产**原料**（树脂/树胶）→ 原住民的手艺 → **战斗物资**（弹药/强化）
>
> 所以主角不是"会种田的打手"。他是**外来者**，他不会这门手艺 ——
> 他能做的是清路、守田、把种子夺回来。田的主人不是他。

这条目前只做设定，**不做成系统**（不做加工界面，见 §8）。

## 7. 落到系统上的八处翻译

见 `05 §1.4`。这里只记结论：**每一条翻译都让原机制更硬，没有一条新增操作。**

| 系统 | 生理 | 变硬在哪 |
|---|---|---|
| 清完一区 | 打通一段堵管 | 清完就该通，不用另解释 |
| 一块地 | 一处断面 | "地来自清图"从设计选择变成因果 |
| 掉种子 | 取回赃物 | 战→农从拾荒变成追赃 |
| 种→收 | 长愈伤封口 | 种田不是治疗，是供料 |
| 守军 | 免疫细胞 | 招安 = 把被黑暗化的原生种**改回来**，不是雇佣（§5.2 网上的一个节点翻转） |
| 袭击 | 感染复发 | 丢地有了病因（§5.2 从邻区重新接上） |
| **两类怪物** | 外来寄生 / 原生被改写（女巫扫帚） | 分类**直接长出一个玩家选择**：外来种只能打，原生种能招安 |
| **物资两分** | 原住民培育 / 树自己分泌 | 可种 = 可量产；不可种 = 有位置（§6） |

## 8. 明确不抄（有依据的减法）

| 不抄 | 依据 |
|---|---|
| 真实愈合时间（3–5 年） | 游戏压到 30 分钟 = 一个生长季。照搬等于永远收不到 |
| **伤口涂封剂 / 药膏道具** | 研究证明无效。**这是一条有事实支撑的"别做"**，比"我们觉得没必要"硬得多 |
| 汁液液体物理 | `00 §5` 已判成本高收益低；只做"看得见在流"，不做模拟 |
| 树的健康度数值 / 修复清单 | `05 §1.7`：会变成第四个系统，稀释丢地的压力 |
| **加工界面**（树脂 → 弹药的手艺） | §6 只把它当设定，不打开第二套 UI。玩家看到的是"田在产弹药"，不是"配方表" |
| **心腐进度条** | §5.5：树能带着烂心活百年，但把它做成仪表就是健康度数值 |

## 9. 一句话记住

> **树不是被打坏的，是被掐住的。它不会愈合，只会带着疤活着。**
> **它也不是被染黑的，是被堵黑 —— 黑就是堵。**

第一句决定**过程**（看不见的慢症），第二句决定**结局**（不复原，只存活），
第三句决定**怪物**（吸与注是同一根管子，所以病与堵是同一件事）。
