# 07 · MVP 与里程碑

> 建 2026-11-26。这份回答**这一版做什么、不做什么、怎么算做完**。
> 范围已定：**只做根系（8 房 + 1 Boss）**，五层其余只写设计不排期。

---

## 1. MVP 一句话

**一个能在手机上、用一只手、从出生点打到根系 Boss 的 25 分钟流程；
打完能把这块地种上，退出，明天回来收一批弹药，再打一遍。**

前半句验"动作手感"，后半句验"经营纵深"。**两句都过才算 MVP 成立。**

## 2. 阶段分解

| 阶段 | 目标 | 完成标志 | 依赖 |
|---|---|---|---|
| **P0 可玩骨架** | 跑跳打、一房 30–50 敌、暗房 | 能连续打 3 个房间不死 | 已有（现原型基本满足） |
| **P1 技能三件** | 投掷（消耗）+ 折叠 + 生长 | 三个技能都能用，且投掷会打空 | 美术：弹药 + 生长 2 态 |
| **P2 经营闭环** | 清图 → 变田 → 种 → 收 → 卖 → 升级 | 能种能收，退出重进数据不丢 | 美术：耕地 + 5 类作物图标 |
| **P3 防守闭环** | 袭击 + 守卫军 + 丢地 | 离线 2 小时后上线，被打一次，守住/丢掉都对 | 美术：兵种（可复用敌人） |
| **P4 Boss + 打磨** | 根系 Boss、手感调优、性能 | 25 分钟流程走通不崩 | 美术：Boss |

> **P2 是分水岭**：P2 之前这是"一个动作 demo"，P2 之后才是"这个项目"。
> 如果排期要砍，砍 P4，不砍 P2。

### 3.1 一个必须先解决的叙事冲突

复用来的 3 种敌人是 **紫色史莱姆 / 蓝色刺球 / 蝙蝠**，
而叙事要的是 **纸团 / 折痕体 / 纸片蝙蝠**。

| 复用资产 | 叙事原型 | 匹配度 |
|---|---|---|
| `enemy_bat` | 纸片蝙蝠 | ✅ 可用（有撕痕的话） |
| `enemy_slime` | 纸团 | ⚠️ 像果冻不像揉皱的纸 |
| `enemy_spike` | 折痕体 | 🔴 完全不像（是刺球，不是折叠的纸） |

**三条出路**（选一条，别拖着）：

| 方案 | 做法 | 代价 |
|---|---|---|
| A. 改叙事迁就资产 | 敌人改成"胶状墨渍系"，不强调纸 | 丢掉"纸"的核心意象，**不建议** |
| B. 重出 2 种敌人 | 按 `ART_GUIDE` 出纸团 + 折痕体 | 2 次出图 + 抠图，1–2 天 |
| C. 先用后换 | MVP 用复用资产占位，P4 再换 | 手感不受影响，但会"先用旧的成了永久" |

> 我建议 **B**。敌人的辨识度是这套叙事的核心，占位方案大概率变成永久。

## 4. 验收标准（可测，不含主观词）

| # | 项 | 判据 |
|---|---|---|
| 1 | 一房时长 | 40–90 秒（计时器实测，剔除外挂时间） |
| 2 | 同屏敌人 | ≤ 8，且 3 秒内能指出哪个是精英 |
| 3 | 打击反馈 | **关掉音效**仍能判断"打中了没有" |
| 4 | 投掷手感 | 空弹时有明确提示（不是静默失败） |
| 5 | 折叠可用性 | 4.5–6.5 格台子稳定能上，7 格稳定上不去 |
| 6 | 生长可用性 | 7 格以上无落脚立面稳定能爬 |
| 7 | 死亡惩罚 | 回暗房，技能/门/田**一样不少** |
| 8 | 种收闭环 | 退出重进，作物成熟进度不丢 |
| 9 | 回访时长 | 收+种+看袭击 **≤ 5 分钟** |
| 10 | 一局时长 | 20–40 分钟走完 8 房 |
| 11 | 随时中断 | 任何时刻杀进程，重进回到最近暗房 |
| 12 | 手机可操作 | 单手（拇指）能完成全部战斗操作 |

## 5. 明确不做（MVP 期间）

| 不做 | 推到哪 |

| 主干 / 四枝 / 树冠 | 后续版本 |

| 音效 / 配乐 | 已有零音频方案，不动 |
| 存档云同步 | 本地存档 |

## 6. 风险

| 风险 | 表现 | 对策 |
|---|---|---|
| **经营把动作挤掉** | 玩到后半段一直在点点点 | 回访 5 分钟硬指标；超了就砍功能 |
| **消耗品劝退** | 玩家不敢用弹药，退化成不打 | 弹药便宜、补给密、空弹提示明确 |
| **敌人形象与叙事错位** | "为什么史莱姆是纸做的" | 方案 B：重出 2 种 |
| **手机看不清** | 同屏 8 只时混战 | 精英标记 + 起手高亮 + 上限 8 |
| **瓦片不能铺** | 地形只能摆，房间看起来空 | P0 必须先解决瓦片 |

## 7. 与美术流程的接口

**美术不走本套 GDD，走 `art/ART_GUIDE.md`。** 本套只提需求（数量、尺寸、语义），
具体怎么出图、怎么抠、什么算过，全在 `art/README.md §4` 的八步里。

一句话：**GDD 说"要一个纸团敌人"，ART_GUIDE 说"怎么做一个合格的纸团敌人"。**
