## 4. 技能

| 项 | 值 | 来源 |
|---|---|---|
| **投掷** 基础伤害 | 20 | 建议（普通怪 2 发死） |
| 投掷冷却 | **350 ms** | 建议 |
| 投掷抛物线初速 | 待实测 | — |
| 投掷穿透 | **2 个目标** | 建议 | 省弹不是主要手段：即使穿透 2，40 敌仍需 40–80 发 |
| 自动瞄准范围 | 前方 8 格，±30° 锥 | 建议 |
| 弹药携带上限 | **80 发** | 建议 | 一局 4.5 房共需 144 发 = 80 携带 + 2×32 暗房补给；**前提是近战扛 60%**（`03 §9.3`） |
| **击杀一只普通怪** | **2 发** | 推算 | 40 血 ÷ 20 伤 |
| **每房耗弹（近战 60%）** | **32 发** | 推算 | 40 敌 × 2 发 × 40% 投掷占比；纯投掷 80 发/房 → 一局打不完 |
| **弹药来源** | **只靠种植 + 暗房补给** | 已定 | 敌人**只掉材料，不掉弹药**——这是种植有意义的唯一保证 |
| 暗房弹药补给 | **40%（32 发）**，每次进入暗房限补一次 | 建议 | **不补满**：补满会让"回暗房→补满→继续"取代种植，30 分钟种地就白设计；补太少（<20）会让 P2 之前打不过房 |
| **折叠** 次数 | 1 次（技能解锁后） | 已定 |
| 折叠强化上限 | +2 次（种强化作物） | 建议 |
| **生长** 最大长度 | 6 格 | 建议 |
| 生长速度 | 4 格/秒（1.5 秒长满） | 建议 |
| 生长持续时间 | 按住时维持，松开 2 秒后回缩 | 建议 |
| **底片** 每点收益 | 血量 +10 / 伤害 +3% / 移速 +2%（三选一） | 建议 |

> **投掷冷却只有 350ms 的原因**：弹药本身已经是限速器，冷却再拉长就是双重惩罚，
> 手感会变得"卡顿"。冷却的作用只是防止一帧内连点打空全部弹药。

## 9. 待实测清单（这些数现在不能当真）

| 量 | 为什么必须实测 |
|---|---|
| 投掷抛物线初速 | 手机自动瞄准 + 抛物线的手感只能上手试 |
| 每个敌人血量 | 40 是估的，要跑一房看"打得累不累" |
| 袭击强度曲线 | 需要 3 次不同离线时长实测 |
| 生长速度 4 格/秒 | 太快像弹射，太慢像等待 |
| 弹药上限 80 | 要试"一房打完还剩几发" |
| 精英体型 1.4× | 要验"3 秒内能不能认出精英" |
| 袭击强度系数（12 小时到顶） | 12 小时太早还是太晚，要试 3 次不同离线时长 |
| 守军削减 −2/兵 | 要验"3 兵满编能不能真的缓解压力"，别做成有跟没有一个样 |
| 暗房补给 40% | 要验"P2 之前（还不能种地）靠暗房补给能不能撑过 3 房" |
| **近战占比 60%** | 这是**算出来的**一局弹药预算要求（`03 §9.3`）。要验"玩家真的会用近战吗"——若实测只有 30%，弹药经济全线崩，必须回头调携带上限或产量 |
| **基质掉率 8%** | 要验"打一房能不能稳定拿到 3 份"。低了变成刷子，高了品质没稀缺感 |
| ★★★ 穿透 3 | 要验"串 3 只在什么地形下会发生"，别做成数值写了、实战永远串不到 |
