# 02 · 战斗系统

> 建 2026-11-26。第一支柱是动作手感，这份是它的落地规则。
> **所有数字见 `06 数值表`，本文只写行为与判据。**

---

## 1. 动作集（继承 `MOVESET.md` 的 10 状态）

| 状态 | 触发 | 关键规格 | 现有帧 |
|---|---|---|---|
| stand | 静止 | — | ✅ |
| walk | 左右 | 8 向输入取水平分量 | ✅ |
| jump / fall | 跳 / 下落 | 单跳 203px（4.22 格） | ✅ |
| 二段跳（折叠） | 空中再按跳 | 331px，**技能解锁后才有** | ✅（复用 jump） |
| attack | 近身补刀 | 无武器，为"护身推开"，非主要输出 | ✅ |
| cast | **投掷** | 主要输出手段，消耗弹药 | ✅ |
| hurt | 受击 | 0.3s 硬直，无敌 0.6s | ✅ |
| crouch / slide | 蹲 / 滑铲 | 手机不常用，保留 | ✅ |
| dash | 冲刺 | 0.12s 无敌，朝背对方向 | ✅ |

> **已有 8 态帧**（复用自 `art/approved/Characters/`），10 状态中有两态复用同一帧。
> 新增技能「生长」需要**按住 + 伸展**两个动作，当前**没有对应帧**——这是美术缺口，
> 见 §7。

## 2. 四个技能（语义命名，不用单字代号）

| 技能 | 类型 | 操作 | 消耗 | 是否做能力门 |
|---|---|---|---|---|
| **投掷** | 输出 | 点按 | **弹药（消耗品）** | ❌ |
| **折叠** | 位移 | 空中点跳 | 无 | ✅ 只锁高度 |
| **生长** | 位移/控场 | **按住** | 无 | ✅ 只锁距离 |
| **底片** | 被动 | 无需操作 | — | ❌ |

### 2.1 投掷

- 抛物线，**自动瞄准最近敌人 + 可手动微调 15°**
  （手机拇指精度不足，全手动瞄准会把命中率做到 40% 以下）
- 命中判定：圆型，半径随弹药类型变化
- **弹药是消耗品**，打空就是打空，逼玩家回田补给
- 弹药有**携带上限**（见 `06 数值表`），不能无限囤

### 2.2 折叠

- 空中点跳 → 空间折一次 → 获得向上位移
- **不消耗任何资源**（位移一旦消耗，玩家会卡死在地图里）
- 强化作物可延长距离 / 增加次数（种一次永久生效）
- 叙事：折一次 = 把脚下的纸对折一次

### 2.3 生长

- **按住**生效，松开收回（或视地形固化，见 `04 关卡与地图` §4）
- 长出藤条/韧带，可：跨过宽坑、向上攀、临时挡住投射物
- **不消耗资源**，理由同折叠
- 生长长度由强化作物决定

### 2.4 底片

- 纯被动，不占按钮位
- 提供：血量上限、伤害加成、移速、弹药上限
- 通过「成长」类作物累积投入（见 `03 经营与种植` §3）

> **按钮布局**：左摇杆 + 右侧 3 键（跳/投掷/生长）。折叠是"空中再按跳"，不占独立键。
> 底片无键。**手机上一只手 3 个键是上限**，第 4 个键会让精准操作崩掉。

## 3. 血量与死亡

| 项 | 规则 | 理由 |
|---|---|---|
| 血量 | **血量条**，不是心 | 精细容错，适配"手感第一" |
| 回复 | 暗房回满 + 少量掉落回血 | — |
| 死亡 | **回最近暗房**，已拿技能/已开的门保留 | 只回退位置 |
| 死亡掉什么 | **什么都不掉**，但当前房间进度重置（重新清） | 恶魔城式；不再叠加资源惩罚 |
| 受击无敌 | 0.6s + 闪烁 | 防止被连续判定打死 |

> **反例（不做）**：死亡掉光弹药。那样死亡就从"回位置"变成"回位置 + 回资源"，
> 是双重惩罚，与已定的惩罚等级不符。

## 4. 打击反馈三件套（缺一不可）

| 件 | 规格 | 缺了会怎样 |
|---|---|---|
| **顿帧** | 命中 40–70ms 冻结（局部，只冻受击者） | 打上去像打空气 |
| **屏幕震动** | 轻击 2px / 重击 5px / 精英 8px，衰减 120ms | 力量感全无 |
| **命中特效** | `fx_hit_00`（已入库）叠在受击点 | 看不出打没打中 |

**验收方法**：关掉音效单看画面，仍能判断"打中了没有"。判断不了就是反馈不够。

## 5. 敌人：两档 × 每层 5 种

### 5.1 难度两档

| 档 | 特征 | 行为差异 | 掉落 |
|---|---|---|---|
| **普通** | 本体大小 | 基础 AI | 弹药材料 |
| **精英** | 1.4× 体型 + 明显色偏 + 头顶标记 | **多一招**，血量 4–6× | **技能升级核心**（唯一来源） |

> 精英必须一眼可辨，否则玩家会误判。判据：**缩小到游戏实际尺寸的下半屏截图，3 秒内能指出哪个是精英。**

### 5.2 每层 5 种，渐进替换（保留 3 换 2）

不是每层全换（美术 ×5 做不完），也不是全复用（玩家会觉得没变化）。
**每进一层：保留 3 种旧敌（可能换皮/加招），替换 2 种新敌。**

| 层 | 敌人编成 | 新增 |
|---|---|---|
| 根系（教学） | 纸团 · 纸片蝙蝠 · 折痕体 · 纸屑群 · 墨渍 | 全部首发 |
| 主干 | 纸团 · 折痕体 · 墨渍 · **+2 新** | 保留 3 换 2 |
| 四枝（每枝） | 各保留 3 + 2 新 | 每枝一套 |

### 5.3 根系 5 种（MVP 要做的全部敌人）

| 名 | 威胁方式 | 教什么 | 弱点 |
|---|---|---|---|
| **纸团** | 直线滚撞 | 教"翻滚躲" | 撞墙会散开 1 秒，此时挨打双倍 |
| **纸片蝙蝠** | 俯冲，飞 | 教"投掷打空中" | 俯冲后 0.8s 落地硬直 |
| **折痕体** | 折起来无敌，展开才可打 | 教"看时机，不是狂按" | 展开瞬间有 0.3s 破绽 |
| **纸屑群** | 数量多（5–8 只小体），围上来 | 教"别被围" | 单体极脆，一次投掷穿多只 |
| **墨渍** | 远程喷墨，命中减速 | 教"优先处理远程" | 喷墨时有 1s 蓄力硬直 |

> 五种对应五种教学点，一个不多一个不少。多一种是浪费美术，少一种会漏教学。

## 6. 战斗节奏（一房 40–90 秒怎么分）

| 屏 | 内容 | 目的 |
|---|---|---|
| 第 1 屏 | 2–3 只普通 | 热身，试探玩家状态 |
| 中间屏 | 4–6 只，含 1 只远程 | 主体战斗 |
| 末屏 | 5–8 只 + 可能 1 只精英 | 收尾，给最大压力 |

**同屏上限 8 只**：超过 8 只，手机小屏会看不清起手动作，手感直接崩。

## 7. 美术缺口（必须补的）

| 缺口 | 现状 | 补法 |
|---|---|---|
| 生长技能的"按住"与"伸展"两态 | **无帧** | 走 `art/ART_GUIDE.md` 流程新出，2 态 |
| 精英怪外观 | 只有普通版 | 先用程序化放大 + 色偏验证，再决定是否重出 |
| 纸屑群 | 无 | 可由纸团缩小 + 变色派生（成本最低） |
| 弹药（3 种尖） | 无 | 小物件，48×48 内 |

> 缺口清单必须在 `07 MVP与里程碑` 里排期，不能只写在这里。

## 8. 不做

| 不做 | 理由 |
|---|---|
| 连招 / 搓招 / 蓄力 | 手机触屏 |
| 手动瞄准（完全自由） | 拇指精度不足，命中率会崩 |
| 消耗资源才能位移 | 位移失败 = 卡死 |
| 主角持武器 | 白哥明确："单纯的拳不应该存在"，但武器也不是方向——技能才是 |
| 无敌帧滥用（翻滚长无敌） | 会退化成"翻滚模拟器"，让战斗失去风险 |
