# 01 · 核心循环

> 建 2026-11-26。这份定义**玩家在不同时间尺度上重复做什么**。
> 所有系统（战斗、经营、关卡）都是为了让这五级循环转起来，转不起来的系统就不该存在。

---

## 1. 五级循环总览

| 级 | 时间尺度 | 玩家在做什么 | 完成的信号 | 暂停点 |
|---|---|---|---|---|
| **L1 一次交锋** | 0.5–3 秒 | 看清敌人动作 → 决定贴身还是后撤 → 投掷/翻滚/补刀 | 敌人变成纸屑 | 无（不可中断） |
| **L2 一个房间** | 40–90 秒 | 进房 → 读地形 → 清 30–50 敌（分 3–6 屏推进）→ 拾取 → 出门 | 房间清空 + 掉落捡完 | 无 |
| **L3 一段推进** | 5–10 分钟 | 连打 3–6 个房间 → 到暗房 → 存档/回血/升级 | 暗房的门打开 | **有（暗房）** |
| **L4 一局** | 20–40 分钟 | 一个子区域 + 小 Boss，或推进到下一个暗房 | 回到暗房或退出 | **有（随时可退，退出即存）** |
| **L5 一次回访** | 隔几小时–隔天 | 上线 → 收菜 → 处理袭击 → 种下一批 → 出门打新的 | 田里空了、地上守住了 | **有（随时）** |

**L4 与 L5 的关系是这套设计的核心**：
L4 是"动作"，L5 是"经营"。单次游玩是 L4，回访理由是 L5。
两者共用一个存档——退出游戏不丢任何东西，但**田里的东西只在现实时间里长**。

> **这五级循环有一个总的动机（2026-11-27 定，`05 §1.3`）**：
> 玩家不是在抢地盘，是在**给一棵树通管**。
> L1–L4 是"清堵"（怪物塞在管道里），L5 是"封口"（断面长愈伤组织）。
> 每一级在生理上都能对上号 —— 这不是修辞，是判断"某个机制该不该加"的尺子：
> **对不上号的机制，就是硬加的。**

## 2. 每一级的具体节奏（带数字）

### L1 一次交锋

| 环节 | 时长 | 设计要求 |
|---|---|---|
| 敌人进入视野 → 起手 | 0.3–0.6s | 起手动作必须能看清（这是"手感可读"的底线） |
| 玩家反应窗口 | ≥ 0.4s | 手机触屏反应比键鼠慢，窗口不能按 PC 定 |
| 命中反馈 | 顿帧 40–70ms + 音效 + 纸屑 | 打击感的主要来源，不能省 |
| 敌人死亡 → 掉落 | ≤ 0.3s | 掉落要立刻可见，否则玩家不知道打没打死 |

**判定标准**：同屏 3–8 只时，玩家应该能在 3 秒内处理掉 1 只普通敌人。做不到就是数值或手感有问题。

### L2 一个房间

| 阶段 | 占时 | 说明 |
|---|---|---|
| 进房 / 读地形 | 3–5s | 手机小屏，地形必须一眼看懂（哪里高、哪里能过） |
| 推进 + 战斗 | 30–70s | 多屏滚动，每屏 3–8 只，累计 30–50 |
| 拾取 | 5–10s | 掉落集中，不要让玩家满地图捡 |
| 出门 | 即时 | — |

**一房 40–90 秒是硬指标。** 超过 90 秒手机玩家会中途退出；低于 40 秒会觉得"没打够"。

### L3 一段推进（到暗房）

3–6 个房间一停。暗房做四件事，缺一不可：

| 功能 | 为什么必须 |
|---|---|
| 存档 | 死亡的惩罚基准 |
| 回满血 | 血量条 + 暗房回满（已定） |
| 花材料升级 | 经营的出口，否则种出来的东西没用处 |
| 看地图 / 规划 | 手机没小地图会迷路 |

### L4 一局（20–40 分钟）

一局 = **一个区域（8–12 房，含 2–3 个安全房）+ 一场 Boss**，约 20–30 分钟。

| 构成 | 数量 | 耗时 |
|---|---|---|
| 战斗房 | 4–5 | 75 秒 × 4.5 ≈ 5.6 分钟 |
| 安全房（出生/暗房） | 2–3 | 1 分钟 × 2.5 ≈ 2.5 分钟 |
| 走路 / 看剧情 / 教学 | — | ≈ 5 分钟 |
| Boss | 1 | ≈ 3 分钟 |
| 补给 / 翻田 / 缓冲 | — | ≈ 5 分钟 |
| **合计** | | **≈ 21 分钟** |

**"可随时中断"的实现**：任何时刻退出 = 从当前暗房继续，不惩罚。

### L5 一次回访（隔几小时）

| 步骤 | 时长 | 玩家心理 |
|---|---|---|
| 收菜 | 1–3 分钟 | "我上次种的熟了没" |
| 处理袭击 | 2–5 分钟 | "我的地还在不在" |
| 重新播种 | 1–2 分钟 | "下一批种什么" |
| 出门 | — | 进入 L4 |

**目标：一次回访 5 分钟内完成，然后自然切入 L4。** 如果经营界面占了 15 分钟，就变成种田游戏了。

## 3. 循环为什么能闭合（正反馈链）

```
打下一个区域
   ↓
该区域变成田（得到一块「地」）+ 敌人解锁为兵种
   ↓
打怪掉「种子」（任何区都掉，深处的品种更好）
   ↓
种子 + 地 → 播种（一颗种子种一块地）
   ↓
按现实时间生长 30 分钟（离线也在长）
   ↓
收：弹药 / 强化 / 底片 / 通货 / 兵营
   ↓
弹药支撑更难的战斗，强化撑开新路线，底片提升属性
   ↓
能打更深的区域 → 更多「地」→ 一次能种更多
```

> 这条链的两个战利品都**直接说明来路**：地来自推开地图，种子来自打赢架。
> 玩家不需要理解任何中间产物 —— 这是 11-27 换掉「基质」的理由（`03 §3.4`）。

**这条链子断在任何一环，游戏就退化成"普通恶魔城"：**

| 断在哪 | 症状 | 修复方向 |
|---|---|---|
| 打下来不能种 | 区域清完就废了，没有回访理由 | 必须清完即解锁耕地 |
| 种出来的没用 | 种田变成无意义点击 | 作物必须接战斗/移动/属性三个出口之一 |
| 田不会被威胁 | 经营没有紧张感，变成挂机 | 必须有袭击事件 |
| 守不住没代价 | 防守变成可跳过的流程 | 丢地必须真的丢（回到怪物领地） |
| 弹药不缺 | 投掷变成无脑连发，消耗品设计失效 | 成熟时间 + 单次产出要有上限 |
| **没种子就没得种** | 打图捡的东西不知道干嘛，战→农断掉 | 种子只从战斗来，且有仓库上限 8 颗（`03 §3.4`） |
| **断了种爬不出来** | 种子 0 + 弹药 0 = 永久卡死 | 暗房补给必须附 1 颗保底种（`03 §3.4`） |
| **近战太弱** | 一局 4.5 房需 144 发，纯投掷只够 1.8 房 | 第一版 1 块地要求近战 ≥50%；2 块地可降到 33%（`03 §9.3` 算的） |

## 4. 负反馈（防止滚雪球）

没有负反馈的成长系统，20 分钟后就没难度了。

| 机制 | 作用 |
|---|---|
| **袭击会丢地** | 田越多，要守的地方越多，摊子铺太大反而守不住 |
| **区域敌人难度递进** | 越深的图敌人越强，旧弹药打不动新图 |
| **弹药有携带上限** | 不能囤到无限，逼玩家回田补给 |
| **成熟按现实时间** | 不能靠"刷"解决，只能靠"等"，天然限速 |

## 5. 一局的实际流程（给关卡设计的靶子）

以 MVP（根系）为例，一次 25 分钟的游玩：

| 分钟 | 在哪 | 发生什么 |
|---|---|---|
| 0–2 | 出生点 | 教学：走、跳、翻滚。**第一个敌人**（纸团，不会主动攻击） |
| 2–4 | 第一个房间 | 打完 3 只，**掉落第一个投掷物**（不是技能，是弹药） |
| 4–6 | 技能房 | **拿到投掷技能**（不可跳过，白哥定的"第一步就应该是获取第一个技能"） |
| 6–12 | 3 个房间 | 用投掷清怪，学会"打空了要捡" |
| 12–15 | 暗房 1 | 存档、第一次看到升级界面、第一次"这块地能种" |
| 15–22 | 3 个房间 + 精英 | 遇到第一只精英，掉技能升级核心 |
| 22–25 | 暗房 2 / 小 Boss | 一局结束点，退出即存 |

> **这个时间轴怎么算出来的**（不是拍脑袋）：
> 4–5 个战斗房 × 75 秒 ≈ 5.6 分钟　+　2 个暗房 × 60 秒 = 2 分钟
> +　教学与走路 5 分钟　+　Boss 3 分钟　+　缓冲 7 分钟 ≈ **25 分钟**
>
> 注意：**一房是 1.5 分钟，不是 3 分钟**。8 房全按 90 秒算也只有 12 分钟，
> 剩下的时间在走路、看剧情、逛暗房——把一房当成 3 分钟会把关卡做得太稀疏。

## 6. 不做的事

| 不做 | 理由 |
|---|---|
| 每局随机地图（roguelite） | 与"探索过的区域变成资源地"冲突——地不能每次重排 |
| 死亡掉光资源 | 死亡惩罚已定为"回暗房"，再加资源清零就是双重惩罚 |
| 离线收益自动到账 | 与"袭击会丢地"冲突。离线时田是"待收 + 待守"状态，不是自动产出 |
| 长按蓄力、组合键、多段搓招 | 手机触屏做不了，与平台决定冲突 |
