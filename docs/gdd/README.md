| 3 | 第一支柱 = **动作手感**，其余三条为它让路 | 第 1 轮 |

| 11 | 关卡**先定整张大地图，再从大地图上切房间**（照《月下》的结构，不照它的单位） | 第 11 次（白哥：「先把整体大地图设计好，然后从大地图中分割出每间房」） |

> 第 11 条的口径：地图格 = **TILE(48)**，不是屏幕格。因为一屏纵向 540÷48 = 11.25 格不是整数，
> 用屏幕格会让房间边界卡在 1/4 格上。数据在 `godot/data/world_map.json`，规则见 `04 §10`。

## 两条最容易犯的错

**① 把位移做成消耗品。** 投掷打空只是少打一下；折叠没"油"是走不了路，玩家卡死在地图里。
代价不对称，所以只有投掷能消耗。

**② 让经营吃掉动作。** 一次回访必须 5 分钟内结束。超过 10 分钟，游戏重心就滑向模拟经营，
与第一支柱（动作手感）直接冲突。

## 三条实现口径（工程定，不需要拍板）

这三条不是玩法决定，是**为了可测、可实现**定下来的口径。改动要说明理由。

| # | 口径 | 在哪 |
|---|---|---|
| 1 | 存档**只承诺到最近写盘点**，不承诺"任何时刻杀进程零损失"（物理上做不到） | `08 §2.1` |
| 2 | 离线**只结算不模拟**：纯函数算来敌数量，战斗仍亲自打；同一存档重算结果必须一致 | `08 §4` |
| 3 | 阶段出口三态 **PASS / CONDITIONAL / BLOCKED**，未解决问题必须登记，不许隐藏 | `07 §2.2` |

## 这份文档怎么维护

| 规则 | 说明 |
|---|---|
| 单一真源 | 一个事实只在一处写。数值只在 `06`，玩法循环只在 `01`，存档规则只在 `08` |

| 不做的事要写 | 「明确不做」比「要做什么」更能防返工 |
| 待定要标 | 没实测的数标「建议」，别装成已定 |
| 与美术切割 | **GDD 提需求（数量/尺寸/语义）、`ART_GUIDE` 定标准与门禁、`art/README` 给命令。三份不重叠**（`07 §7`） |
