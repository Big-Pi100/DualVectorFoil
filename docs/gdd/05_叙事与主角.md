# 05 · 叙事与主角

> 建 2026-11-26。继承 `STORY.md` v0.3 的内核，但**有一节必须推翻**（§4，赤手论证）。
> 叙事服从支柱排序：动作手感 > 经营 > 叙事。所以叙事**不许打断操作**。

---

## 1. 内核（v0.3 保留，未改）

**你给一个人拍了张照片。现在你得自己走进那张照片，把他弄出来。**

**每一张照片都是一枚二向箔。** 按下快门那一瞬，一个立体的东西只被留下一个平面——
它还认得出是谁，但厚度没有了。

所以这个故事里没有天外武器、没有反派文明、没有从宇宙射来的光。
**只有你按下去的那一下。**

### 1.1 三条不可动的设定

| # | 设定 | 为什么不能动 |
|---|---|---|
| 1 | **快门是玩家按的** | 这是产品本身在做的事，不是修辞 |
| 2 | **背面是空的** | 不是黑，是"没有"。恐怖来自「完整」消失，不来自破坏 |
| 3 | **像素是事实，不是风格** | 三维的人拍成平面，细节按面积丢失。画出来就是一百多像素宽 |

### 1.2 开场

不是爆炸，是**快门声**——而且它在你开始玩之前就已经响过了。

第一个画面不是主角，是**你自己的相册**：里面有一张刚拍的照片。
点开它，那张照片变成游戏画面。

**从这一刻起，"横版"不是关卡设计，是这张照片的形状。**

### 1.3 世界树的生理：两条流，一个病灶（2026-11-27 白哥定主线）

白哥给的主线：**世界树各部分被怪物入侵，物质的运输和产生都出了问题；
主角要做的是让它恢复一棵树的正常生命状态。**

这句话里有两个词是硬的 —— **运输**和**产生**。它们不是修辞，是植物真实的两套系统：

| 系统 | 走什么 | 方向 | 在哪 |
|---|---|---|---|
| **上行** | 水 + 矿质 | 根 → 叶，单向 | 木质部（木头里面） |
| **下行** | 糖 | 叶 → 根 / 果，主要向下 | 韧皮部（树皮里面） |

**关键事实（可查，不是比喻）：这两条流能被独立切断。**

环剥（girdling）剥掉一圈树皮 → 韧皮部断、木质部完好 →
糖下不去、根活活饿死，**但叶子照样有水、照样绿，地上部分能看起来健康好几个月**
（松树苗断糖后存活 140 天以上；根先耗尽淀粉，然后整棵跟着死）。

这条事实决定了整个故事的**病灶形状**：

> **树不是被打坏的，是被掐住的。表面还绿，底下已经在饿死。**

这比"怪物占领了城堡"高一个量级，因为它给了玩家一个**看不出来的敌人** ——
你在冠部打得顺利、叶子绿得发亮，而根在饿死。等你看出来，已经晚了。

**第二条事实，决定结局：树不"愈合"，它只"隔离"。**

受伤的组织不会长回原样。树在伤口边缘长**愈伤组织（callus）**，
把这处伤**包起来**、隔开（CODIT：树的区隔化）。术语上"healing"是误称 ——
真实时间尺度是：愈伤 2–4 周开始，小伤口 1–2 个生长季封口，5cm 以上要 3–5 年。

这条和 §1 的内核**完全同构**，不是巧合：

> 照片里的人回不到立体。树的伤口也回不到原样。
> 主角自己就是那个"回不去的人"，他在修一棵"修不好、只能带着疤活"的树。

所以结局不是"树恢复了"，是**"树带着疤活着"**。这比拯救世界诚实，也更像这个游戏。

### 1.4 六处翻译：系统词换成生理词

这不是给玩家看的设定表，是**为了判断"某个机制该不该存在"**。
每次要加一条规则，先问：它在生理上对应什么？对应不上，就是硬加的。

| 系统里叫什么 | 生理上是什么 | 为什么这个翻译**让机制更硬** |
|---|---|---|
| 清完一个区域 | 打通一段被堵的管 | 怪物是**塞在管里的东西**，不是占领者 —— 所以清完就该通，不用另解释 |
| 得到一块地 | **露出一处断面** | 断面是清的结果，不是奖励。**所以"地来自清图"不是设计选择，是因果** |
| 打怪掉种子 | 取回被它偷走的籽 | 怪物是**吸食者**，籽在它嗉囊里 —— 战→农从"拾荒"变成"追赃" |
| 种植 → 收成 | 长出愈伤组织，把断面封住 | 树自己封口，你只提供材料 —— 所以种田**不是治疗**，是供料 |
| 守卫军 | 免疫细胞 | 招安 = 把它**改写**成这棵树的一部分，不是雇它打工 |
| 袭击 | 感染复发 | 伤口还没封好，病原又从这里进来 —— 所以"守不住会丢地"有了病因 |

**顺带解释了三条一直只能靠"设计意图"撑着的硬规则：**

| 硬规则 | 原来的理由 | 现在的理由 |
|---|---|---|
| 敌人**只掉种子，不掉弹药**（`03 §3.1`） | "掉了就没人种田了"（利益论证） | 弹药是**树自己的防御组织**（刺、硬壳、树脂），怪物身上没有。它只能掉赃物 |
| 地只能靠清图拿（`03 §3.4`） | "让推图有意义"（动机论证） | 断面只能由**清掉堵塞物**露出来。拿不到就是没有 |
| 守不住 → 作物清空、地块保留（`03 §5`） | "惩罚是丢一茬，不是永久失去" | 伤口还在，只是**又感染了**。地不会消失，会重新堵上 |

> 三条里前两条原来靠"我们希望玩家这样做"撑着，现在靠"世界就是这样"撑着。
> **这是这次设定最大的收益：它把三个设计意图变成了三个物理后果。**

### 1.5 一条禁令：树的生理只做表现，不接数值

这条必须先写死，否则整个项目会滑向"生态修复模拟器"，与第一支柱（动作手感）打架。

| 做 | 不做 |
|---|---|
| 管道里的汁**看得见在流** | 不显示"上行通量 +12%" |
| 叶子从黄转绿、断面边缘往里收 | 不做"树的健康度"进度条 |
| 恢复度只决定**你能去哪** + 终局一句台词 | 不接任何数值加成（不加速成熟、不加产量） |
| 玩家只感知"这块清了、能种了" | 不给"修复任务清单" |

**为什么不接数值**：一旦接上，玩家就会开始优化它，它就变成第四个系统，
而 `00 §5` 已经判过"原位播种的治愈长线"不成立 —— 理由是**治愈长线会稀释丢地的压力**。
这里保持同一条线：**树只负责给"为什么"提供依据，不负责给玩家一个待办列表。**


## 2. 主角：形象没变，但"为什么能打"变了

### 2.1 主线裁定（2026-11-26）

| 项 | 决定 |
|---|---|
| 主角形象 | **身份卡机制**：玩家给的照片决定长相 |
| 母版的作用 | **骨架模板**：提供 3.3 头身比例、8 态姿势、蜡笔质感 |
| 第一版怎么做 | **直接用母版（棕发红围巾小孩）当默认主角**，可玩可验收 |
| 身份卡功能 | 列为后续功能，不阻塞 MVP |

**为什么母版能当模板**：`CANON §3.1` 原来的问题是"角色卡是展示用大头像，2.5 头身、
头占 40%、脚还被裁掉"，直接进游戏必崩。现在的母版恰好解决了这一半——
它提供**体型与姿势**，玩家照片只提供**身份特征**：

| 来源 | 提供什么 |
|---|---|
| 母版（`art/reference/character_style_sheet.jpg`） | 3.3 头身、8 态姿势、轮廓画法、蜡笔笔触 |
| 玩家照片 | 发色 / 发型 / 胡须 / 服装配色 / 配饰 |
| 合成 | 把特征"画"进母版骨架，不走"从零生成" |

> 这比原来的"三段管线"可控得多：体型不再漂，因为骨架是固定的。
> 技术细节见 `art/ART_GUIDE.md §12.4`。

### 2.2 换装 = 换人（保留）

不是 skin。你换一张照片，就是换了一个被拍平的人。
这句话让"角色自定义"从功能变成了叙事。

## 3. 四个技能的叙事挂法

技能不是"解锁的能力"，是**这个世界碎掉之后剩下的东西**。

| 技能 | 设定名 | 是什么 | 叙事 |
|---|---|---|---|
| **投掷** | 棱 | 硬物被拍平后剩下的尖——刀口、钉头、玻璃碴 | 拍平了，尖还在。它硌人 |
| **折叠** | 折 | 空间本身的一道折痕 | 二维的世界要往上走，只有一种办法：**把照片折起来** |
| **生长** | 撑 | 会生长的东西——藤、韧带、筋 | 它们还在试图把人撑起来，哪怕人已经平了 |
| **底片** | 底 | 影像类——底片、相纸、显影液 | 记录了「这个人曾经有多厚」 |

**能力门不需要教程提示，它自己就是一个隐喻**：
那道 4.5 格高的台子，叙事上就是一句台词——**「这里必须折。」**

## 4. 推翻：§2.4「赤手」整节作废

`STORY.md` §2.4 有一整节在论证"他凭什么能打——赤手，用拳"。
**这一节作废**，白哥 2026-11-26 明确：

> "四碎片技能，必须要有技能，**单纯的拳不应该存在**，用户进入游戏的第一步就应该是获取第一个技能。"

改动连带：

| 原设定 | 现在 |
|---|---|
| 主角武器：无（用拳） | 主角有技能，投掷是主要输出 |
| "赤手空拳"作为世界观的一部分 | 改成"他捡起了这个世界碎掉的东西当武器" |
| `attack` 状态是主输出 | `attack` 降级为**近身护身推开**，非主要输出 |
| 已入库的 `player_attack_00` 帧 | 保留可用（就是出拳），但语义从"攻击"变成"推开" |

## 5. 敌人：被拍坏的东西

| 名 | 是什么 | 读法 |
|---|---|---|
| 纸团 | 揉皱的纸 | 滚过来，展开时是脸 |
| 纸片蝙蝠 | 撕成三缺口的纸 | 扑，翅膀有撕痕 |
| 折痕体 | 反复对折的纸 | 折起来是无害的薄片，展开才有体积 |
| 纸屑群 | 撕碎的边角料 | 单片毫无威胁，聚起来才可怕 |
| 墨渍 | 打翻的显影液 | 远程喷，黏住人就慢 |

（详细行为见 `02 战斗系统` §5.3）

## 6. 对话框系统（手机优先）

| 项 | 规则 | 理由 |
|---|---|---|
| 触发 | 只在**暗房 / Boss 前 / 拾取关键物** | 战斗中途弹框会打断手感 |
| 呈现 | 屏幕下方 30% 区域，半透明纸色底 | 不遮角色 |
| 推进 | 点击任意处 | 手机唯一可靠的操作 |
| 跳过 | **整段可跳过**，跳过不惩罚 | 不看剧情的玩家也是玩家 |
| 单句长度 | ≤ 40 字（手机上 3 行以内） | 超过要换行，破坏节奏 |
| 是否配音 | 不做 | 成本与包体 |

**总量控制**：一局（25 分钟）的对话总量 **≤ 12 句**。
这不是小说，是动作游戏。

## 7. 叙事不做什么

| 不做 | 理由 |
|---|---|
| 战斗中途弹对话 | 打断动作，违反支柱排序 |
| 长过场动画 | 手机用户会跳 |
| 旁白解说设定 | 让场景自己说 |
| 主角开口说话 | 他不说话，所以"换照片=换人"才成立 |
| 收集品文本（几百字） | 与 3–5 分钟回访节奏冲突 |
| **树的生理做成数值 / 任务清单** | 会变成第四个系统，稀释"守不住会丢地"的压力（§1.5，与 `00 §5` 同一条线） |

## 8. 待定

| 项 | 待定原因 |
