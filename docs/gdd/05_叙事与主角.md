# 05 · 叙事与主角

> 建 2026-11-26。继承 `STORY.md` v0.3 的内核，但**有一节必须推翻**（§4，赤手论证）。
> 叙事服从支柱排序：动作手感 > 经营 > 叙事。所以叙事**不许打断操作**。

---

## 1. 内核（v0.3 保留，未改）

**你给一个人拍了张照片。现在你得自己走进那张照片，把他弄出来。**

**每一张照片都是一枚二向箔。** 按下快门那一瞬，一个立体的东西只被留下一个平面——
它还认得出是谁，但厚度没有了。

所以这个故事里没有天外武器、没有反派文明、没有从宇宙射来的光。
**只有你按下去的那一下。**

### 1.1 三条不可动的设定

| # | 设定 | 为什么不能动 |
|---|---|---|
| 1 | **快门是玩家按的** | 这是产品本身在做的事，不是修辞 |
| 2 | **背面是空的** | 不是黑，是"没有"。恐怖来自「完整」消失，不来自破坏 |
| 3 | **像素是事实，不是风格** | 三维的人拍成平面，细节按面积丢失。画出来就是一百多像素宽 |

### 1.2 开场

不是爆炸，是**快门声**——而且它在你开始玩之前就已经响过了。

第一个画面不是主角，是**你自己的相册**：里面有一张刚拍的照片。
点开它，那张照片变成游戏画面。

**从这一刻起，"横版"不是关卡设计，是这张照片的形状。**

### 1.3 世界树的生理：两条流，一个病灶（2026-11-27 白哥定主线）

白哥给的主线：**世界树各部分被怪物入侵，物质的运输和产生都出了问题；
主角要做的是让它恢复一棵树的正常生命状态。**

这句话里有两个词是硬的 —— **运输**和**产生**。它们不是修辞，是植物真实的两套系统：

| 系统 | 走什么 | 方向 | 在哪 |
|---|---|---|---|
| **上行** | 水 + 矿质 | 根 → 叶，单向 | 木质部（木头里面） |
| **下行** | 糖 | 叶 → 根 / 果，主要向下 | 韧皮部（树皮里面） |

**关键事实（可查，不是比喻）：这两条流能被独立切断。**

环剥（girdling）剥掉一圈树皮 → 韧皮部断、木质部完好 →
糖下不去、根活活饿死，**但叶子照样有水、照样绿，地上部分能看起来健康好几个月**
（松树苗断糖后存活 140 天以上；根先耗尽淀粉，然后整棵跟着死）。

这条事实决定了整个故事的**病灶形状**：

> **树不是被打坏的，是被掐住的。表面还绿，底下已经在饿死。**

这比"怪物占领了城堡"高一个量级，因为它给了玩家一个**看不出来的敌人** ——
你在冠部打得顺利、叶子绿得发亮，而根在饿死。等你看出来，已经晚了。

**第二条事实，决定结局：树不"愈合"，它只"隔离"。**

受伤的组织不会长回原样。树在伤口边缘长**愈伤组织（callus）**，
把这处伤**包起来**、隔开（CODIT：树的区隔化）。术语上"healing"是误称 ——
真实时间尺度是：愈伤 2–4 周开始，小伤口 1–2 个生长季封口，5cm 以上要 3–5 年。

这条和 §1 的内核**完全同构**，不是巧合：

> 照片里的人回不到立体。树的伤口也回不到原样。
> 主角自己就是那个"回不去的人"，他在修一棵"修不好、只能带着疤活"的树。

所以结局不是"树恢复了"，是**"树带着疤活着"**。这比拯救世界诚实，也更像这个游戏。

### 1.4 六处翻译：系统词换成生理词

这不是给玩家看的设定表，是**为了判断"某个机制该不该存在"**。
每次要加一条规则，先问：它在生理上对应什么？对应不上，就是硬加的。

| 系统里叫什么 | 生理上是什么 | 为什么这个翻译**让机制更硬** |
|---|---|---|
| 清完一个区域 | 打通一段被堵的管 | 怪物是**塞在管里的东西**，不是占领者 —— 所以清完就该通，不用另解释 |
| 得到一块地 | **露出一处断面** | 断面是清的结果，不是奖励。**所以"地来自清图"不是设计选择，是因果** |
| 打怪掉种子 | 取回被它偷走的籽 | 怪物是**吸食者**，籽在它嗉囊里 —— 战→农从"拾荒"变成"追赃" |
| 种植 → 收成 | 长出愈伤组织，把断面封住 | 树自己封口，你只提供材料 —— 所以种田**不是治疗**，是供料 |
| 守卫军 | 免疫细胞 | 招安 = 把它**改写**成这棵树的一部分，不是雇它打工 |
| 袭击 | 感染复发 | 伤口还没封好，病原又从这里进来 —— 所以"守不住会丢地"有了病因 |
| **两类怪物** | 外来寄生 / 原生被改写（女巫扫帚） | 分类**长出一个玩家选择**：外来种只能打，原生种能招（§1.5） |
| **物资两分** | 原住民培育 / 树自己分泌 | 可种 = 可量产；不可种 = 有位置。稀有物品能种则主线可刷（§1.6） |

**顺带解释了三条一直只能靠"设计意图"撑着的硬规则：**

| 硬规则 | 原来的理由 | 现在的理由 |
|---|---|---|
| 敌人**只掉种子，不掉弹药**（`03 §3.1`） | "掉了就没人种田了"（利益论证） | 弹药是**树自己的防御组织**（刺、硬壳、树脂），怪物身上没有。它只能掉赃物 |
| 地只能靠清图拿（`03 §3.4`） | "让推图有意义"（动机论证） | 断面只能由**清掉堵塞物**露出来。拿不到就是没有 |
| 守不住 → 作物清空、地块保留（`03 §5`） | "惩罚是丢一茬，不是永久失去" | 伤口还在，只是**又感染了**。地不会消失，会重新堵上 |

> 三条里前两条原来靠"我们希望玩家这样做"撑着，现在靠"世界就是这样"撑着。
> **这是这次设定最大的收益：它把三个设计意图变成了三个物理后果。**

### 1.5 入侵者：寄生虫，不是占领军（2026-11-27 白哥定）

§1.3 说了树被掐住，没说**谁**掐的。白哥定了四件事：

| 项 | 设定 |
|---|---|
| 本质 | **寄生虫**。不是军队、不是文明、不是反派政权 —— 是寄生 |
| 目的 | **把世界树变成黑暗世界树**。不是杀死它，是**改宗**它 |
| 手段 | 既**吸取**物质与养料，也**注入**黑暗物质 |
| 两类 | **外来物种**（入侵者本身）+ **原生物种被黑暗化** |

**"既吸又注"在生理上只用一根管子。**

吸器（haustorium，拉丁语 *haurire* = 喝）是寄生植物唯一的专门器官。它接进寄主的
维管束 —— 木质部与韧皮部**都接** —— 而且**是双向的**：真实研究里，水、光合产物、
mRNA、蛋白质、病毒、植原体都从这条通道双向走（已知 **56 种病毒**能经菟丝子从病株转到健株）。

> 所以"注入黑暗物质"**不需要另编机制**。它和"吸走养料"是同一个器官的两个方向。
> 一句设定，省掉一个将来会被问倒的地方。

**它们是一张网，不是一群散兵。**

一株菟丝子能同时寄生多个相邻寄主，把它们**连起来**；连抗虫信号都能经这张网传到一米外。
三个后果，`03` 里都已经在用：

- 感染会**跨区** —— 不用解释"怪物为什么跑到别的区去了"
- 清干净一个区，它可能从邻区**重新接上** = §1.4 那条"感染复发"的物理版
- 招安 = 把网上的一个**节点翻过来**用

**"黑暗"不是染上去的，是堵出来的。**

病原真菌侵入木质部后的真实链条：菌丝与孢子占满导管空间 + 分泌毒素 + 刺激薄壁细胞
产生凝胶和侵填体（tylosis）→ **导管栓塞**；颜色从黄褐转黑褐，**堵得越重、黑得越深**。
蓝变真菌还会在菌丝里制造**黑色素**，把边材直接染成深蓝到黑。

> **在树身上，黑和堵是同一件事。**
> 所以"黑暗化"和"运输中断"不用写成两套设定 —— 玩家看到的黑，就是堵。

**为什么"原生物种被黑暗化"比"凭空冒出魔物"好。**

真实对应的形态是**女巫扫帚**（witches' broom）：被寄生的树长出一簇纠结丛生的枝条，
枝条肿胀。病原先在皮下长两三年才冒芽 —— **冒出来时，看着健康的枝条其实早已感染**。

关键不在畸形，在于：

> **树还是那棵树，只是长得不像自己了。**
> 被黑暗化的怪，玩家**认得出它原来是树里的什么**。
> 认得出，才谈得上招安 —— 你没法招安一个完全陌生的东西。

**由此定下两类怪的分工**（形态表在 §5）：

| | 外来物种 | 原生物种被黑暗化 |
|---|---|---|
| 形态 | 没有原生形态：藤、吸器、花 —— 纯粹是寄生结构 | **还认得出原来是啥**，但长歪了、肿胀、纠结 |
| 能不能招安 | **不能**，只能打 | **能**，改回来当守卫军（带着痕） |
| 掉什么 | 种子（赃物积在它体内） | 种子，外加一个选择：留它一命 |
| 读法 | "入侵者" | "它本来是这棵树的一部分" |

**这条给玩家的不是新系统，是一个选择：打，还是招。** 不占一帧 UI，只用形态和反应区分。

### 1.6 物资两个来路（白哥定）

| | **可种** | **不可种** |
|---|---|---|
| 是谁的 | 世界树**原住民**的种植物 | **树本身**的产出 |
| 是什么 | 把树液培育成的武器与防御组织 | 树脂、树胶、单宁、虫瘿、果实 |
| 系统里是 | **战斗物资**：弹药 / 强化 / 成长 / 兵营 | **稀有 / 任务物品**：解锁、开门、剧情 |
| 拿法 | 播种 → 等 → 收 | 走到特定位置**采** |

中间隔着一道**加工**：树产原料 → 原住民的手艺 → 战斗物资。

> **所以主角不种田。他不会这门手艺。**
> 他能做的是清路、守田、把被偷走的种子夺回来 —— 田的主人是原住民。
> 系统上玩家仍然点播种，但叙事上他是在**替不在场的人下种**。

这条的完整落点在 `03 §0` 与 `06 §6.1`；这里只立规矩：**稀有物品永远不能种。**
一旦能种，主线就能靠种田刷过去。

### 1.7 一条禁令：树的生理只做表现，不接数值

这条必须先写死，否则整个项目会滑向"生态修复模拟器"，与第一支柱（动作手感）打架。

| 做 | 不做 |
|---|---|
| 管道里的汁**看得见在流** | 不显示"上行通量 +12%" |
| 叶子从黄转绿、断面边缘往里收 | 不做"树的健康度"进度条 |
| 恢复度只决定**你能去哪** + 终局一句台词 | 不接任何数值加成（不加速成熟、不加产量） |
| 玩家只感知"这块清了、能种了" | 不给"修复任务清单" |

**为什么不接数值**：一旦接上，玩家就会开始优化它，它就变成第四个系统，
而 `00 §5` 已经判过"原位播种的治愈长线"不成立 —— 理由是**治愈长线会稀释丢地的压力**。
这里保持同一条线：**树只负责给"为什么"提供依据，不负责给玩家一个待办列表。**


## 2. 主角：形象没变，但"为什么能打"变了

### 2.1 主线裁定（2026-11-26）

| 项 | 决定 |
|---|---|
| 主角形象 | **身份卡机制**：玩家给的照片决定长相 |
| 母版的作用 | **骨架模板**：提供 3.3 头身比例、8 态姿势、蜡笔质感 |
| 第一版怎么做 | **直接用母版（棕发红围巾小孩）当默认主角**，可玩可验收 |
| 身份卡功能 | 列为后续功能，不阻塞 MVP |

**为什么母版能当模板**：`CANON §3.1` 原来的问题是"角色卡是展示用大头像，2.5 头身、
头占 40%、脚还被裁掉"，直接进游戏必崩。现在的母版恰好解决了这一半——
它提供**体型与姿势**，玩家照片只提供**身份特征**：

| 来源 | 提供什么 |
|---|---|
| 母版（`art/reference/character_style_sheet.jpg`） | 3.3 头身、8 态姿势、轮廓画法、蜡笔笔触 |
| 玩家照片 | 发色 / 发型 / 胡须 / 服装配色 / 配饰 |
| 合成 | 把特征"画"进母版骨架，不走"从零生成" |

> 这比原来的"三段管线"可控得多：体型不再漂，因为骨架是固定的。
> 技术细节见 `art/ART_GUIDE.md §12.4`。

### 2.2 换装 = 换人（保留）

不是 skin。你换一张照片，就是换了一个被拍平的人。
这句话让"角色自定义"从功能变成了叙事。

## 3. 四个技能的叙事挂法

技能不是"解锁的能力"，是**这个世界碎掉之后剩下的东西**。

| 技能 | 设定名 | 是什么 | 叙事 |
|---|---|---|---|
| **投掷** | 棱 | 硬物被拍平后剩下的尖——刀口、钉头、玻璃碴 | 拍平了，尖还在。它硌人 |
| **折叠** | 折 | 空间本身的一道折痕 | 二维的世界要往上走，只有一种办法：**把照片折起来** |
| **生长** | 撑 | 会生长的东西——藤、韧带、筋 | 它们还在试图把人撑起来，哪怕人已经平了 |
| **底片** | 底 | 影像类——底片、相纸、显影液 | 记录了「这个人曾经有多厚」 |

**能力门不需要教程提示，它自己就是一个隐喻**：
那道 4.5 格高的台子，叙事上就是一句台词——**「这里必须折。」**

## 4. 推翻：§2.4「赤手」整节作废

`STORY.md` §2.4 有一整节在论证"他凭什么能打——赤手，用拳"。
**这一节作废**，白哥 2026-11-26 明确：

> "四碎片技能，必须要有技能，**单纯的拳不应该存在**，用户进入游戏的第一步就应该是获取第一个技能。"

改动连带：

| 原设定 | 现在 |
|---|---|
| 主角武器：无（用拳） | 主角有技能，投掷是主要输出 |
| "赤手空拳"作为世界观的一部分 | 改成"他捡起了这个世界碎掉的东西当武器" |
| `attack` 状态是主输出 | `attack` 降级为**近身护身推开**，非主要输出 |
| 已入库的 `player_attack_00` 帧 | 保留可用（就是出拳），但语义从"攻击"变成"推开" |

## 5. 敌人：被改写的，和闯进来的

按来源分两类（§1.5 定的）。**同一个表里分两类，形态就是标识，不做 UI 标记。**

| 名 | 来源 | 是什么 | 读法 | 能招安 |
|---|---|---|---|---|
| 纸团 | **原生** | 揉皱的纸 | 滚过来，展开时是脸 | ✅ |
| 纸片蝙蝠 | **原生** | 撕成三缺口的纸 | 扑，翅膀有撕痕 | ✅ |
| 折痕体 | **原生** | 反复对折的纸 | 折起来是无害的薄片，展开才有体积 | ✅ |
| 纸屑群 | **原生** | 撕碎的边角料 | 单片毫无威胁，聚起来才可怕 | ✅ |
| 墨渍 | **原生** | 打翻的显影液 | 远程喷，黏住人就慢 | ✅ |

（详细行为见 `02 战斗系统` §5.3）

### 5.1 一条已经成立的推论：纸 vs 非纸

现有五个敌人**全部是纸质的** —— 因为它们是**照片世界里的东西**被揉、撕、折、打翻。
也就是说：**MVP 的五个敌人全是"原生物种被黑暗化"，一个外来种都没有。**

这不算缺，反而给了分类一个免费的视觉判据：

| 看它是什么材质 | 哪一类 | 能不能招安 |
|---|---|---|
| **纸 / 墨 / 折痕** | 原生被黑暗化 | ✅ 能。它是这棵树里的东西，只是长歪了 |
| **藤 / 胶 / 孢子 / 虫瘿** | **外来物种** | ❌ 不能。它本来就不属于这里 |

> 玩家不需要任何提示，**看它是不是纸就知道该不该留手。**

### 5.2 外来物种：MVP 不做，但必须现在定形

第一版不做，理由是美术成本（非纸质材质是新管线）。但形态现在要定，
否则以后加进来会和纸系混在一起，分类就废了。

| 项 | 建议 | 依据 |
|---|---|---|
| 形态语言 | **吸器**：细的、会缠的、往你身上扎的 | 寄生植物唯一的专门器官，真实存在 |
| 材质 | 湿、黏、有弹性 —— 与纸的干脆形成对立 | "湿"是纸最怕的东西，视觉上天然敌对 |
| 行为 | 不追，**缠**；缠住就抽你的血（吸 = 掉血上限，不是掉血） | 吸器是双向的，"抽"就是它的攻击 |
| 弱点 | 怕火/怕干 | 与"湿"对立 |
| 掉落 | **只掉种子，不掉材料** | 外来种身上没有树自己的东西（`03 §3.1` 的物理原因） |
| 出现区 | 主干起，冠最密 | 越靠近输导主脉，寄生越密 |

**一条必须守住的**：外来种**不能招安**，也不该长得像原住民。
它是唯一种"看起来明显不属于这里"的东西 —— 这种异质感是它的全部辨识度。

### 5.3 "黑暗世界树"在游戏里长什么样（建议，待裁决）

白哥给了反派的目的，那"目的达成会怎样"就得有个形态。**但我不能给它做一个进度条** ——
那就是 §1.7 禁止的健康度数值，等于把树变成第四个系统。

建议：**不做一个进度，做地图的颜色。**

| 阶段 | 画面 | 玩家读到什么 |
|---|---|---|
| 开局 | 深的区域**已经是黑的**（材质发暗、边缘有黑纹、汁液流得慢） | "已经晚了一步" —— 不是从零开始 |
| 清完一区 | 那一段从黑**回到木色**，断面渗出清亮的汁 | 这是玩家唯一能看到的"树的进度" |
| 终局 | 没有全亮，**有几处永远黑着** | 带疤活着（§1.3） |

> **关键：这不是新状态，是复用"已清 / 未清"那个既有状态，只给它一个视觉。**
> 区域清了就是木色，没清就是黑的 —— 零新增系统、零 UI、零数值。
> 玩家看到的是"这棵树在我手里一点点回来"，而不是"腐化度 47%"。

**为什么建议而不是直接写死**：这涉及美术工作量的分配（每个区要做两套材质），
要不要这么干，白哥定。

## 6. 对话框系统（手机优先）

| 项 | 规则 | 理由 |
|---|---|---|
| 触发 | 只在**暗房 / Boss 前 / 拾取关键物** | 战斗中途弹框会打断手感 |
| 呈现 | 屏幕下方 30% 区域，半透明纸色底 | 不遮角色 |
| 推进 | 点击任意处 | 手机唯一可靠的操作 |
| 跳过 | **整段可跳过**，跳过不惩罚 | 不看剧情的玩家也是玩家 |
| 单句长度 | ≤ 40 字（手机上 3 行以内） | 超过要换行，破坏节奏 |
| 是否配音 | 不做 | 成本与包体 |

**总量控制**：一局（25 分钟）的对话总量 **≤ 12 句**。
这不是小说，是动作游戏。

## 7. 叙事不做什么

| 不做 | 理由 |
|---|---|
| 战斗中途弹对话 | 打断动作，违反支柱排序 |
| 长过场动画 | 手机用户会跳 |
| 旁白解说设定 | 让场景自己说 |
| 主角开口说话 | 他不说话，所以"换照片=换人"才成立 |
| 收集品文本（几百字） | 与 3–5 分钟回访节奏冲突 |
| **树的生理做成数值 / 任务清单** | 会变成第四个系统，稀释"守不住会丢地"的压力（§1.7，与 `00 §5` 同一条线） |
