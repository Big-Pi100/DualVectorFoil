## 2. 产品形态（先定死，避免后面每章都吵）

| 项 | 决定 | 影响 |
|---|---|---|
| 平台 | **手机触屏优先** | 动作复杂度上限受触屏约束；房间要适配小屏 |
| 单局时长 | **20–40 分钟，可随时中断** | 不是碎片小游戏，是"坐下来打一段" |
| 死亡 | **回最近暗房，已拿能力与已开的门保留** | 只回退位置，不回退资源以外的进度 |
| 房间 | **多屏滚动**，一房累计 30–50 敌、同屏 3–8 | 不是一屏到底，也不是无缝大地图 |
| 叙事 | **对话框**（可跳过） | 关键节点停一下，不抢操作时间 |
| MVP | **只做根系（教学层）+ 一个 Boss** | 五层只写设计，不排期 |

## 3. 四大支柱（冲突时按序号让路）

| # | 支柱 | 具体含义 | 谁必须为它让路 |
|---|---|---|---|
| **1** | **动作手感** | 复刻《重生细胞》的动作层：翻滚无敌帧、打击顿帧、输入缓冲、顶点滞空。**手感不好，其余全白搭** | 其余三条 |
| **2** | **经营纵深** | 打下来的区域变成你的田，种出来的东西变成你的战力，守不住会丢回去。**这是与"一般恶魔城"的分界线** | 叙事密度、关卡复杂度 |
| 3 | 叙事反差 | 世界越像小孩画的，被压平这件事越残忍。恐怖来自「完整」消失，不来自破坏 | 美术冲击力 |
| 4 | 身份认同 | 主角是玩家给的那张照片。换装 = 换人，不是 skin | — |

> **第 2 条是本项目唯一的产品级差异点。** 纯恶魔城满地都是，纯种田满地都是，
> 「打下来的地能种、种的东西能卖、守不住会丢」这条链子把两者焊在一起。
> 任何砍掉经营的方案，都等于砍掉这个项目存在的理由。

## 4. 目标玩家

不是"所有喜欢动作游戏的人"。画像要窄，不然每个决定都要平均。

| 维度 | 判断 |
|---|---|
| 玩过《重生细胞》手游版 | 是。手感基准是它，不需要教学 |
| 接受"打完还要回来种地" | 是。这是筛选器，不接受的人不是目标用户 |
| 单次可投入 | 20–40 分钟，每天 1–2 次 |
| 不要求 | 不要求反应神速、不要求背板、不要求会算数值 |

## 5. 明确不做（写下来防复发）

| 不做 | 理由 |
|---|---|
| 原位播种的"治愈长线"（`Dual_Vector_Foil` 那套，作物被染灰但不枯死） | 与本项目"守不住会丢地"的压力设计相反 |
| 低挫败 / 难度自适应 | 与第一支柱（动作手感）冲突 |
| 一屏到底的小体量版本 | 与 30–50 敌/房冲突 |
| 纯拳战斗 | 白哥 2026-11-26 明确否定："单纯的拳不应该存在" |
| 消耗品式的位移 | 位移失败 = 卡死地图，代价不对称（见 `03 经营与种植` §2） |
| 爬藤模拟 / 树叶粒子堆满屏 / 树汁液体物理 | `CANON §2.2` 已判为成本高收益低 |
